# Guía CMMI para el Proyecto GHE

> *"CMMI no es un checklist — es un camino de mejora continua en madurez de proceso."*

---

## 1. Resumen de CMMI

**CMMI** (Capability Maturity Model Integration) es un marco del Software Engineering Institute (SEI/CMU) que define 22 áreas de proceso para mejorar la madurez del desarrollo de software.

### Niveles de Madurez

| Nivel | Nombre | Descripción |
|---|---|---|
| 1 | Inicial | Procesos caóticos, dependen de personas |
| 2 | Gestionado | Procesos gestionados por proyecto |
| 3 | Definido | Procesos estandarizados en la organización |
| 4 | Cuantitativamente gestionado | Procesos medidos y controlados |
| 5 | En optimización | Mejora continua basada en datos |
