### 1.2. Medicamentos Contraindicados Absolutos

| Medicamento | Riesgo | Trimestre más peligroso |
|---|---|---|
| **Tetraciclinas** (doxiciclina, tetraciclina) | Detección de dientes, inhibición crecimiento óseo | 2do-3er trimestre |
| **Fluoroquinolonas** (ciprofloxacino, levofloxacino) | Daño cartilaginoso fetal | Todos |
| **Sulfamidas** (trimetoprim/sulfametoxazol) | Kernicterus neonatal, defectos tubo neural | 1er trimestre y >32 sem |
| **Paroxetina** (ISRS) >20mg | Malformación cardíaca | 1er trimestre |
| **Inhibidores de la ECA** (enalapril, captopril, ramipril) | Displasia renal, oligohidramnios, muerte fetal | Todos |
| **ARA II** (losartán, valsartán, irbesartán) | Similar a IECA | Todos |
| **Warfarina** | Warfarin embryopathy (hipoplasia nasal, disco epifisario) | 6-12 semanas |
| **Metotrexato** | Aborto, malformaciones graves | Todos |
| **Isotretinoína** (retinoide oral) | Malformaciones SNC, cardíacas, faciales | Todos |
| **Ergotamina** | Contracción uterina, aborto | Todos |
| **Estatinas** (atorvastatina, simvastatina) | Dislipidemia fetal, defectos SNC | Todos |
| **Litio** (1er trimestre) | Malformación cardíaca (Ebstein) | 1er trimestre |
| **Dadson** (ác. valproico) | Defectos tubo neural (10%) | 1er trimestre |
| **Carbamazepina** | Defectos tubo neural, hepatotoxicidad neonatal | 1er trimestre |
| **Dimetil-fumarato** | No se conoce seguridad | Todos |

### 1.3. Medicamentos con Uso Relativo (requiere justificación)

| Medicamento | Riesgo | Cuándo usar |
|---|---|---|
| **Ibuprofeno** | Cierre prematuro conducto arterioso | Solo <32 semanas, por <48h |
| **Aspirina alta dosis** | Sangrado fetal | Solo si indicación estricta |
| **Prednisona/Prednisolona** | Macrosomía, diabetes gestacional | Solo si condición autoinmune severa |
| **Litio** (2do-3er trimestre) | Toxicidad neonatal | Si beneficio > riesgo |
| **Benzodiazepinas** | Síndrome de floppy baby | Solo crisis, dosis mínima |

## 3. Specs de clojure.spec

### 3.1. Specs de Embarazo

```clojure
;; Edad gestacional
(s/def :ghe.obstetric/gestational-weeks (s/and int? #(<= 0 % 42)))
(s/def :ghe.obstetric/gestational-days (s/and int? #(<= 0 % 6)))
(s/def :ghe.obstetric/gestational-age
  (s/keys :req-un [:ghe.obstetric/gestational-weeks
                    :ghe.obstetric/gestational-days]))

;; Fecha de última regla
(s/def :ghe.obstetric/lmp-date inst?)

;; Fecha probable de parto
(s/def :ghe.obstetric/edd-date inst?)

;; Riesgo obstétrico
(s/def :ghe.obstetric/risk-level #{:low :medium :high :critical})

;; Tipo de control prenatal
(s/def :ghe.obstetric/visit-type #{:first :routine :followup :emergency})

;; Presentación fetal
(s/def :ghe.obstetric/fetal-presentation #{:cephalic :breech :transverse :lie})

;; Edema
(s/def :ghe.obstetric/edema #{:none :mild :moderate :severe})

;; Proteinuria
(s/def :ghe.obstetric/proteinuria #{:negative :trace :1plus :2plus :3plus :4plus})

;; Tipo de parto
(s/def :ghe.obstetric/delivery-type #{:vaginal :cesarean :assisted-vaginal :forceps})

;; Estado del recién nacido
(s/def :ghe.obstetric/neonatal-status #{:healthy :premature :low-birth-weight :sick :deceased})

;; Score de Bishop
(s/def :ghe.obstetric/bishop-score (s/and int? #(<= 0 % 13)))

;; Score de APGAR
(s/def :ghe.obstetric/apgar-score (s/and int? #(<= 0 % 10)))

;; Glucosa en embarazo
(s/def :ghe.obstetric/glucose-pregnancy
  (s/keys :req-un [:ghe.obstetric/fasting-glucose]
          :opt-un [:ghe.obstetric/glucose-1h-post50
                   :ghe.obstetric/glucose-1h-post100
                   :ghe.obstetric/glucose-2h-post100]))

;; Signos vitales maternos
(s/def :ghe.obstetric/maternal-vitals
  (s/keys :req-un [:ghe.vital/bp-systolic
                    :ghe.vital/bp-diastolic
                    :ghe.vital/heart-rate
                    :ghe.vital/weight]
          :opt-un [:ghe.vital/temperature
                   :ghe.vital/o2-saturation]))

;; Control prenatal completo
(s/def :ghe.obstetric/prenatal-visit
  (s/keys :req-un [:ghe.obstetric/visit-number
                    :ghe.obstetric/gestational-age
                    :ghe.obstetric/maternal-vitals
                    :ghe.obstetric/edema
                    :ghe.obstetric/proteinuria]
          :opt-un [:ghe.obstetric/fundal-height
                   :ghe.obstetric/fetal-heart-rate
                   :ghe.obstetric/fetal-presentation
                   :ghe.obstetric/notes]))
```

## 4. Modelo de Datos Obstétrico

### 4.1. Tablas SQLite

```sql
-- Embarazo
CREATE TABLE pregnancies (
    id TEXT PRIMARY KEY,
    patient_id TEXT NOT NULL REFERENCES patients(id),
    lmp_date DATE,
    edd_date DATE,
    gestational_age_weeks INTEGER,
    gestational_age_days INTEGER,
    current_trimester INTEGER CHECK (current_trimester BETWEEN 1 AND 4),
    risk_factors TEXT,
    risk_level TEXT CHECK (risk_level IN ('low', 'medium', 'high', 'critical')),
    prenatal_visits_count INTEGER DEFAULT 0,
    status TEXT DEFAULT 'active' CHECK (status IN ('active', 'completed', 'complicated', 'terminated')),
    delivery_date DATE,
    delivery_type TEXT,
    birth_weight DECIMAL(5,2),
    apgar_score_1min INTEGER,
    apgar_score_5min INTEGER,
    neonatal_status TEXT,
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    sync_status TEXT DEFAULT 'pending'
);

-- Control prenatal
CREATE TABLE prenatal_visits (
    id TEXT PRIMARY KEY,
    pregnancy_id TEXT NOT NULL REFERENCES pregnancies(id),
    consultation_id TEXT NOT NULL REFERENCES consultations(id),
    visit_number INTEGER NOT NULL,
    gestational_age_at_visit INTEGER,
    -- Signos vitales maternos
    blood_pressure_systolic INTEGER,
    blood_pressure_diastolic INTEGER,
    heart_rate INTEGER,
    weight DECIMAL(5,2),
    weight_gain DECIMAL(4,2),
    temperature DECIMAL(4,1),
    oxygen_saturation INTEGER,
    -- Examen obstétrico
    fundal_height DECIMAL(4,1),
    fetal_heart_rate INTEGER,
    fetal_position TEXT,
    edema TEXT CHECK (edema IN ('none', 'mild', 'moderate', 'severe')),
    proteinuria TEXT,
    -- Laboratorio
    hemoglobin DECIMAL(4,2),
    hematocrit DECIMAL(4,2),
    glucose DECIMAL(5,2),
    uric_acid DECIMAL(4,2),
    ast DECIMAL(5,1),
    alt DECIMAL(5,1),
    platelets INTEGER,
    creatinine DECIMAL(4,2),
    tsh DECIMAL(4,2),
    -- Plan
    next_visit_date DATE,
    risk_level TEXT,
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    recorded_by TEXT NOT NULL,
    sync_status TEXT DEFAULT 'pending'
);

-- Monitoreo fetal
CREATE TABLE fetal_monitoring (
    id TEXT PRIMARY KEY,
    pregnancy_id TEXT NOT NULL REFERENCES pregnancies(id),
    visit_id TEXT REFERENCES prenatal_visits(id),
    gestational_age INTEGER,
    -- Biometría fetal
    bpd DECIMAL(4,2),       -- Diámetro biparietal (mm)
    hc DECIMAL(4,2),        -- Circunferencia cefálica (mm)
    ac DECIMAL(4,2),        -- Circunferencia abdominal (mm)
    fl DECIMAL(4,2),        -- Longitud femoral (mm)
    efw DECIMAL(5,2),       -- Peso fetal estimado (g)
    -- Líquido amniótico
    afi DECIMAL(3,1),       -- Índice de líquido amniótico
    -- Presentación
    presentation TEXT,
    -- Notas
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    recorded_by TEXT NOT NULL
);

-- Plan de parto
CREATE TABLE birth_plans (
    id TEXT PRIMARY KEY,
    pregnancy_id TEXT NOT NULL REFERENCES pregnancies(id),
    planned_delivery_type TEXT,
    planned_date DATE,
    -- Evaluación previa
    pelvic_assessment TEXT,
    estimated_fetal_weight DECIMAL(5,2),
    fetal_presentation_final TEXT,
    -- Indicaciones
    indications_for_cesarean TEXT,
    indications_for_induction TEXT,
    -- Plan
    birth_plan_notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Score de riesgo predictivo
CREATE TABLE risk_scores (
    id TEXT PRIMARY KEY,
    pregnancy_id TEXT NOT NULL REFERENCES pregnancies(id),
    visit_id TEXT REFERENCES prenatal_visits(id),
    model_name TEXT NOT NULL,
    risk_score DECIMAL(5,2),
    risk_level TEXT,
    factors TEXT,  -- JSON con factores que contribuyen
    recommendation TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    validated BOOLEAN DEFAULT FALSE,
    outcome TEXT  -- Para learning: qué pasó realmente
);

-- Resultados (para aprendizaje)
CREATE TABLE outcomes (
    id TEXT PRIMARY KEY,
    pregnancy_id TEXT NOT NULL REFERENCES pregnancies(id),
    outcome_type TEXT NOT NULL,
    outcome_value TEXT,
    -- Para validación de predicciones
    predicted_risk_score DECIMAL(5,2),
    predicted_outcome TEXT,
    actual_outcome TEXT,
    prediction_correct BOOLEAN,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Log de validaciones
CREATE TABLE validation_log (
    id TEXT PRIMARY KEY,
    entity_type TEXT NOT NULL,
    entity_id TEXT NOT NULL,
    field_name TEXT NOT NULL,
    validation_type TEXT NOT NULL,
    input_value TEXT,
    expected_range TEXT,
    result TEXT CHECK (result IN ('valid', 'warning', 'blocked')),
    message TEXT,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
