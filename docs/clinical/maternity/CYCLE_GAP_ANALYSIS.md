# Análisis del Ciclo Completo de Atención Materno-Infantil

> *"La salud materna no empieza con el embarazo — empieza ANTES y termina DESPUÉS."*

---

## 1. Mapa del Ciclo Completo

```
PRE-EMBARAZO          EMBARAZO              PARTO            POSPARTO           INFANCIA
(antes de concebir)  (40 semanas)         (0-24h)          (0-6 meses)        (0-5 años)
     │                    │                  │                 │                  │
     ▼                    ▼                  ▼                 ▼                  ▼
┌──────────┐    ┌──────────────┐    ┌──────────┐    ┌──────────────┐    ┌──────────┐
│ Planif.  │    │ Control      │    │ Parto    │    │ Cuidados     │    │ Crecim.  │
│ familiar │ →  │ prenatal     │ →  │ seguro   │ →  │ posparto     │ →  │ desarrollo│
│ Salud    │    │ Monitoreo    │    │ Emergen- │    │ Lactancia    │    │ Vacunas  │
│ preconcep│    │ Predicción   │    │ cias     │    │ Depresión    │    │ Nutrition│
└──────────┘    └──────────────┘    └──────────┘    └──────────────┘    └──────────┘
     │                │                  │                 │                  │
  FASE 0          FASE 1-5           FASE 6           FASE 7-8           FASE 9-10
  (NO CUBIERTA)   (CUBIERTA ✅)      (CUBIERTA ✅)    (PARCIAL ⚠️)      (NO CUBIERTA)
```

## 2. Vacíos Identificados por Fase

### FASE 0: PRE-EMBARAZO ❌ NO CUBIERTA

| Área | Descripción | Estado |
|---|---|---|
| **Planificación familiar** | Anticoncepción, preparación preconcepcional | ❌ |
| **Salud preconcepcional** | Evaluación antes de embarazarse | ❌ |
| **Vacunación preconcepcional** | Rubéola, hepatitis B, varicela | ❌ |
| **Genética** | Asesoría genética, tamizaje | ❌ |
| **Nutrición preconcepcional** | Ácido fólico pre-embarazo | ❌ |
| **Enfermedades crónicas** | Control antes de embarazarse | ❌ |
| **Salud mental** | Evaluación antes de embarazo | ❌ |

### FASE 7: POSPARTO TEMPRANO (0-6 semanas) ⚠️ PARCIAL

| Área | Descripción | Estado |
|---|---|---|
| **Cuidados inmediatos posparto** | Primera hora, lactancia temprana | ⚠️ Parcial |
| **Hemorragia posparto** | Protocolo detallado | ✅ |
| **Eclampsia posparto** | Detección y manejo | ⚠️ Parcial |
| **Infección posparto** | Signos, prevención, tratamiento | ⚠️ Parcial |
| **Trombosis venosa** | Prevención, detección | ❌ |
| **Depresión posparto** | Screening, tratamiento | ✅ |
| **Lactancia** | Apoyo, dificultades, seguimiento | ✅ |

| **Cesárea** | Cuidados de herida, movilización | ❌ |

### FASE 8: POSPARTO TARDÍO (6 semanas - 6 meses) ⚠️ PARCIAL

|---|---|---|

### FASE 9: INFANCIA TEMPRANA (0-12 meses) ❌ NO CUBIERTA

### FASE 10: INFANCIA (1-5 años) ❌ NO CUBIERTA

| Área | Descripción | Estado |
|---|---|---|

## 3. Resumen de lo que Falta

| Fase | Cobertura actual | Áreas faltantes | Prioridad |
|---|---|---|---|
| **Pre-embarazo** | 0% | Planificación familiar, salud preconcepcional, vacunas, genética | Alta |
| **Embarazo** | 90% | Nutrición específica, ejercicio, viajes, trabajo | Baja |
| **Parto** | 85% | Monitoreo fetal intraparto detallado, partograma avanzado | Media |
| **Posparto temprano** | 60% | Cesárea, episiotomía, trombosis, infección, ejercicio | Alta |
| **Posparto tardío** | 40% | Nutrición, ejercicio, salud sexual, cicatriz | Media |
| **Infancia 0-12m** | 20% | Neonatología, vacunas, crecimiento, desarrollo, screening | Crítica |
| **Infancia 1-5a** | 10% | Crecimiento, desarrollo, vacunas, nutrición, enfermedades | Crítica |
