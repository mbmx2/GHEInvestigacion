# Cumplimiento NOM-024-SSA3-2012: Sistemas de Información

---

## 1. Resumen

La NOM-024 regula los Sistemas de Información de Registro Electrónico para la Salud (SIRES). Si GHE captura datos clínicos electrónicamente, es un SIRES y le aplica esta norma.

### Diferencia con NOM-004

| Aspecto | NOM-004 | NOM-024 |
|---|---|---|
| Qué regula | El expediente (contenido) | El sistema (tecnología) |
| Aplica a | Todos (papel o digital) | Solo sistemas electrónicos |
| Enfoque | Qué documentar | Cómo funciona el software |

## 2. Requisitos Técnicos

### 2.1. Seguridad (Art. 5)

| Requisito | GHE Implementation | Estado |
|---|---|---|
| Autenticación de usuarios | Login con password hasheado (bcrypt) | ✅ |
| Control de acceso por roles | RBAC (admin, doctor, nurse, pharmacy) | ✅ |
| Registro de auditoría | Tabla `audit_log` con hash SHA-256 | ✅ |
| Cifrado en tránsito | TLS 1.3 | ✅ |
| Cifrado en reposo | AES-256 en SQLite | ✅ |
| Protección contra malware | Dependencias escaneadas | ✅ |
| Gestión de parches | Proceso de actualización documentado | ✅ |

### 2.2. Integridad (Art. 6)

| Requisito | GHE Implementation | Estado |
|---|---|---|
| No alteración no autorizada | Registros inmutables después de firma | ✅ |
| Trazabilidad de cambios | Audit log con old/new values | ✅ |
| Hash de integridad | SHA-256 por cada registro | ✅ |
| Sellado de tiempo | Timestamp con zona horaria | ✅ |

### 2.3. Disponibilidad (Art. 7)

| Requisito | GHE Implementation | Estado |
|---|---|---|
| Acceso cuando se necesita | Offline-first (siempre disponible) | ✅ |
| Respaldo periódico | Backup diario automatizado | ✅ |
| Recuperación ante desastres | Restauración documentada | ✅ |
| Continuidad de operaciones | SQLite local, sin servidor | ✅ |

### 2.4. Interoperabilidad (Art. 8)

| Requisito | GHE Implementation | Estado |
|---|---|---|
| Intercambio de información | FHIR R4 (en desarrollo) | 🔄 |
| Estándares de mensajería | HL7 CDA (planificado) | 📋 |
| Codificación de diagnósticos | CIE-10 integrado | ✅ |
| Codificación de medicamentos | Nombre genérico + marca | ✅ |

### 2.5. Confidencialidad (Art. 9)

| Requisito | GHE Implementation | Estado |
|---|---|---|
| Protección de datos personales | LFPDPPP compliance | ✅ |
| Consentimiento para tratamiento | Formulario de consentimiento | ✅ |
| Derechos ARCO | Exportación/eliminación de datos | ✅ |
| Aviso de privacidad | Documento incluido en UI | ✅ |

## 3. Certificación SIRES

### Proceso de certificación ante DGIS:

1. **Solicitud** ante Dirección General de Información en Salud
2. **Evaluación** de conformidad (PEC)
3. **Verificación** de guías GIIS aplicables
4. **Emisión** de certificado

### GIIS aplicables a GHE:

| GIIS | Descripción | Estado |
|---|---|---|
| SGSI | Sistema de Gestión de Seguridad de la Información | ✅ Cumple |
| SIS-CEX | Consulta Externa | ✅ Cumple |
| SIS-CSB | Salud Bucal | No aplica |
| SIS-CSM | Salud Mental | No aplica |
| SIS-CPF | Planificación Familiar | 🔄 Futuro |
| SIS-DET | Detecciones | 🔄 Futuro |
