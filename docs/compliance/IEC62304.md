# Cumplimiento IEC 62304: Ciclo de Vida del Software Médico

> *"IEC 62304 no es burocracia — es la promesa de que cada cambio es rastreable y seguro."*

---

## 1. Resumen

La IEC 62304 es el estándar internacional para el ciclo de vida del software médico. Define los procesos, actividades y tareas necesarios para el desarrollo y mantenimiento seguro del software.

### Por qué IEC 62304 para GHE

| Razón | Beneficio |
|---|---|
| **Riesgo para el paciente** | Software médico puede causar daño si falla |
| **Certificación** | Requisito para certificación como dispositivo médico |
| **Trazabilidad** | Cada cambio se puede rastrear a su origen |
| **Calidad** | Procesos documentados = resultados predecibles |
| **Mantenimiento** | Facilita actualizaciones seguras |

---

## 2. Clasificación de Software (Art. 4)

La IEC 62304 clasifica el software según el riesgo de daño al paciente:

| Clasificación | Descripción | GHE |
|---|---|---|
| **Clase A** | Sin posibilidad de contribuir a una situación peligrosa | No aplica |
| **Clase B** | Puede contribuir a una situación peligrosa pero no causar lesión grave | No aplica |
| **Clase C** | Puede contribuir a una situación pelogrosa y causar lesión grave o muerte | **GHE = Clase C** |

**GHE es Clase C** porque:
- Maneja prescripciones médicas
- Monitorea signos vitales maternos
- Puede detectar o no detectar complicaciones potencialmente mortales (preeclampsia, hemorragia)

## 4. Trazabilidad

La trazabilidad es el corazón de IEC 62304:

```
Requisito → Diseño → Código → Test → Validación

Ejemplo:
REQ-001: "El sistema debe calcular la edad gestacional"
    ↓
DES-001: "Función calculate-gestational-age en patient.clj"
    ↓
COD-001: "(defn calculate-gestational-age [lmp-date] ...)"
    ↓
TST-001: "(deftest test-calculate-gestational-age ...)"
    ↓
VAL-001: "Prueba clínica con 50 pacientes reales"
```

## 5. Gestión de Riesgos (ISO 14971)

### 5.1. Identificación de Riesgos

| Riesgo | Severidad | Probabilidad | Riesgo | Mitigación |
|---|---|---|---|---|
| Error en cálculo de edad gestacional | Alta | Baja | Medio | Tests unitarios + validación clínica |
| Pérdida de expediente | Crítica | Baja | Alto | Backup automático + offline-first |
| Error en prescripción | Crítica | Baja | Alto | CDS alerts + doble verificación |
| Acceso no autorizado | Alta | Media | Alto | RBAC + cifrado + auditoría |
| Fallo del sistema | Alta | Baja | Medio | Offline-first + redundancia |

### 5.2. Controles de Riesgo

| Control | Tipo | Eficacia |
|---|---|---|
| Tests automatizados | Prevención | Alta |
| Code review | Prevención | Alta |
| Auditoría de accesos | Detección | Media |
| Backup automático | Mitigación | Alta |
| Alertas de CDS | Detección | Alta |
